# Triple Espresso

## Project description

This project (part of the TripleTen bootcamp) was about making the front end of a cafeteria using HTML and CSS, where the user can check information about the cafeteria like schedule and address. The user can also contact the cafeteria through a form.

I did practice how to use CSS properties like position and flexbox and regarding HTML I did practice how to build a proper form witht the form, inputs and labels tags.

## Technologies

- HTML
- CSS
